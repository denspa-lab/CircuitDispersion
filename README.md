## Overview

CircuitDispersion is a standalone helper program that introduces variations into LTspice circuit component values, model parameters, subcircuits, and values passed between hierarchical circuit levels, and examines the resulting spread in circuit characteristics through multiple simulations.

Without directly modifying the original schematic, the program allows you to select the parameters to be varied and the analysis method either through the GUI or from saved settings. It then generates a separate ASC file containing the required analysis commands, together with the associated plot settings. When required, it can also run LTspice, collect measurement results, display graphs, and clean up temporary generated files.

As with MultiCircuitViewer, directives such as `Python:exec`, `Python:Sim`, and `Python:param` within the schematic are not interpreted as instructions to launch CircuitDispersion.

# CircuitDispersion 操作説明書

本書はCircuitDispersion R0.5.23の操作方法を示します。

## 【概要】

CircuitDispersionは、LTspice回路の部品定数、モデルパラメーター、
サブサーキットおよび階層回路の受け渡し値へばらつきを与え、複数回の
シミュレーションから回路特性の散らばりを調べる独立ヘルパープログラムです。

元回路図を直接変更せず、ばらつき対象と解析方法をGUIまたは保存済み設定から選び、
解析コマンドを含む別のASCと関連プロット設定を生成します。必要に応じてLTspiceの
実行、測定結果の集計、グラフ表示および一時生成物の後片付けまで行います。

MultiCircuitViewerと同じく、回路図内の`Python:exec`、`Python:Sim`、
`Python:param`などをCircuitDispersionの起動指示として解釈しません。

## 【主な構成ファイル】

| ファイル | 役割 |
|---|---|
| `CircuitDispersion.py` | GUI、設定保存、解析回路生成、実行および結果集計を行う本体 |
| `denspa.py` | ASC選択ダイアログと、必要時のローカル`Autopy.ini`作成 |
| `LTsimplefunctions.py` | `makeUniNetlist()`によるLTspice NET生成 |
| `LTSpicePlot.py` | RAWおよび測定LOGのLTspice表示 |
| `Autopy.ini` | 起動時作業フォルダーで使用するLTspice実行環境。内容はASCII-JSON |
| `<元回路名>_CircuitDispersion_analysis.txt` | 部品設定と解析履歴を保存する統合設定 |
| `<元回路名>.asc` | 利用者が用意する、正常にシミュレーションできる元回路図 |
| `<元回路名>.plt`、`<元回路名>.log.plt` | 任意の通常波形用および測定LOG用プロット設定 |

解析に必要な`Normal.meas`、`MonteCarlo.meas`、`Gauss.meas`、
`MaxMinSel.meas`および`MaxMin.meas`は本体へ内蔵され、選択した解析に応じて
生成ASCと同じフォルダーへ展開されます。Excelファイルは実行時に参照しません。

## 【使用前の準備】

1. Windows上でLTspiceとPythonを利用できる状態にします。
2. 使用するPython環境へ`spicelib==1.5.1`と、本プロジェクトが必要とする
   パッケージを準備します。
3. 元回路図単体で、目的の解析が正常に完了することをLTspiceで確認します。
4. 評価する特性を、元回路図へ有効な`.meas`としてあらかじめ記述します。
5. 波形を自動表示する場合は、元回路図と同じ基底名の`.plt`または
   `.log.plt`を用意します。
6. CircuitDispersionを起動するフォルダーを決め、そのフォルダーを
   カレント作業フォルダーとして起動します。

spicelibの版と実際のインストール先は、CircuitDispersionを起動するPythonで
確認してください。

```text
python -m pip show spicelib
```

仮想環境を有効化しない場合は、その環境の`python.exe`を直接指定します。

```text
"D:\Documents\Python\python3.14\py314\Scripts\python.exe" -m pip show spicelib
```

### 作業フォルダーと`Autopy.ini`

- 起動時のカレント作業フォルダーがローカル作業フォルダーです。入力ASCが
  下位または別のフォルダーにあっても、この基準は変わりません。
- `Autopy.ini`はローカル作業フォルダーにあるものだけを使用します。入力ASCの
  フォルダー、親フォルダー、プログラム配置フォルダーまたはPATH上を探索しません。
- 回路図の読込み時に`AscEditor`がシンボルとサブサーキットのライブラリを探索するため、
  設定、生成、単独実行を含むすべての起動で`Autopy.ini`が必要です。
- 存在しなければ、同梱`denspa.py --ini`を親と同じPythonで起動し、
  ローカル作業フォルダーへ作成します。作成やLTspice選択をキャンセルすると、
  別の設定へ切り替えずエラー終了します。
- `exec.Lib`にはLTspiceのシステムデータルートを指定します。プログラムが固定の
  `lib`を補い、`AscEditor`がその下の`sym`または`sub`を探索します。
- `exec.Libs`内の`exec.Lib`以外の項目はユーザーライブラリのルートです。利用者が
  構成した自由な階層を保つため、プログラムは`lib`、`sym`、`sub`または`cmp`を
  追加せず、記載順のまま`AscEditor`のカスタム探索パスへ渡します。
- 各指定は存在するフォルダーの絶対パスでなければなりません。`exec.Lib`配下に
  固定の`lib`がない場合も、別の場所を自動探索せず設定エラーになります。
- NET生成、シミュレーションおよび結果表示には、同じ`Autopy.ini`の
  `exec.Prog`に記録されたLTspiceだけを使用します。

## 【運用方法】

- 元回路図は直接変更しません。生成済み回路図ではなく、常に元のASCを入力します。
- 元回路図の`.meas`を測定対象の正本とします。CircuitDispersionから測定式を
  対話入力する機能はありません。
- GUIで対象部品、公差関数、必要なモデルまたは受け渡しパラメーターを設定します。
- 部品のチェック状態または番号の振り直しによって選択番号が変わった場合、次に開く
  解析設定画面の開始番号と終了番号は、選択中番号の最小値と最大値へ自動更新されます。
  範囲を意図的に狭める場合は、自動更新後に開始番号または終了番号を手動調整します。
- 部品選択が変わっていない場合は、以前に手動設定した開始番号と終了番号を維持します。
- 選択状態と解析履歴は元回路図と同じフォルダーの統合設定TXTへ保存され、
  次回起動時に復元されます。旧設定TXTは利用者が削除する運用とし、現行形式へ
  補完または移行して読み込む互換処理はありません。
- 通常起動はGUIで設定して生成します。保存済み設定をそのまま再生成する場合は
  `--generate`を使用します。
- `--generate`は既存生成物を既定で上書きします。上書きを禁止するときだけ
  `-n`または`--no-overwrite`を指定します。
- `-o FILE`または`--output FILE`は`--generate`から独立して使用でき、
  GUI操作と非GUI生成のどちらでも出力ASCを別名にできます。
- `--run`を指定した場合だけ、生成後にLTspice実行、集計および表示を行います。

## 【起動方法】

引数なしで起動すると、別プロセスのファイルダイアログからASCを1つ選択できます。

```text
python CircuitDispersion.py
```

相対パスまたは絶対パスでも指定できます。空白を含むパスは引用符で囲みます。

```text
python CircuitDispersion.py 回路図検証\7_NT5_AC.asc
python CircuitDispersion.py "D:\回路フォルダー\example.asc"
```

主なオプションは次のとおりです。

| オプション | 動作 |
|---|---|
| `--generate` | GUIを開かず保存済み統合設定から再生成 |
| `-n`、`--no-overwrite` | `--generate`時に既存生成先があれば、何も変更せず終了 |
| `-o FILE`、`--output FILE` | 生成ASCを別名指定。単独でも`--generate`併用でも使用可能 |
| `--run` | 生成後にLTspice実行、結果集計および表示 |
| `--run-only` | 設定TXTと再生成を使わず、指定済みASCから実行・集計・表示 |
| `-H NAME`、`--hist NAME` | `--run-only`で表示する`.meas`名。複数名はカンマ区切り |
| `--keep` | `--run`または`--run-only`後も自動生成物を残す |
| `--mult` | 通常RAWと測定LOGを別々のLTspiceで表示 |
| `--reset-history` | 部品設定を残して解析履歴だけを削除 |
| `--version` | バージョンを表示して終了 |

`-n`は`--generate`と同時に使用します。`--keep`と`--mult`は`--run`または
`--run-only`と同時に使用します。`-H`は`--run-only`専用です。
`--reset-history`は生成・実行オプションと併用できません。

`-o`の相対名は入力ASCのフォルダーを基準とし、拡張子を省略すると`.asc`を
補います。元ASCと同じ出力、`.asc`以外、および存在しない出力先フォルダーは
指定できません。

ファイルダイアログをキャンセルした場合は、入力を変更せず正常終了します。
存在しないファイル、ASC以外、および生成済み`_CircuitDispersion.asc`を
入力した場合はエラー終了します。

## 【使用例】

### GUIで設定して既定名へ生成

```text
python CircuitDispersion.py "D:\回路\example.asc"
```

### GUIで設定して別名へ生成

```text
python CircuitDispersion.py "D:\回路\example.asc" -o evaluation.asc
```

### 保存済み設定から既定上書きで再生成

```text
python CircuitDispersion.py "D:\回路\example.asc" --generate
```

### 既存生成物を保護して再生成

```text
python CircuitDispersion.py "D:\回路\example.asc" --generate -n
```

### 別名生成後にLTspiceで実行し、生成物を残す

```text
python CircuitDispersion.py "D:\回路\example.asc" --generate -o evaluation.asc --run --keep
```

### RAWと測定LOGを別々のLTspiceで表示

```text
python CircuitDispersion.py "D:\回路\example.asc" --generate --run --mult
```

### 調整済みASCを設定TXTなしで単独実行

```text
python CircuitDispersion.py Trial.asc --run-only --hist Gain,MagdB
```

ファイル名を省略するとファイルダイアログから調整済みASCを選択します。

```text
python CircuitDispersion.py --run-only -H Gain
```

ヒストグラムが不要なら`-H`または`--hist`を省略します。指定する名前は
`V(out)`等のRAW信号名ではなく、元ASCに記述した`.meas`測定名です。
`-H`はMonte CarloまたはGaussの統計解析で使用します。

### 解析履歴だけをリセット

```text
python CircuitDispersion.py "D:\回路\example.asc" --reset-history
```

## 【処理の流れ】

1. CircuitDispersionを起動し、元ASCを引数またはファイルダイアログで指定します。
2. ASCを読み、変換可能な部品、モデルおよび受け渡しパラメーターを列挙します。
3. 保存済み統合設定があれば現在の回路図と照合して復元します。
4. GUI操作では対象、公差関数、解析タイプおよび必要なヒストグラム測定変数を設定します。`--generate`では
   保存済み設定をそのまま使用します。
5. 元ASCを変更せず、解析コマンドを含む生成ASC、関連PLTおよび必要な解析マクロを
   出力します。出力後に元ASCの不変と生成内容を検証します。
6. `--run`がなければ生成物を残して終了します。
7. `--run`時はローカル`Autopy.ini`を準備・検証し、同じ`exec.Prog`でNET生成と
   LTspiceシミュレーションを行います。
8. `.meas`結果を集計して結果ログを保存し、利用可能なPLTに対応するグラフを表示します。
   各グラフを開いた直後にLTspiceの`Zoom Extents`を自動実行し、波形全体が
   表示範囲へ収まるようにします。ヒストグラムが有効な場合はLOG読込み、対象抽出、
   描画ライブラリの初期化、非表示Figureの生成・配置および描画までを続けます。
9. ヒストグラムの準備が完了すると、LTspiceを閉じる操作を待たず、spicelib既定の
   50ビンで直ちに表示し、`ヒストグラムを閉じるまで待機します。`と表示します。
   対象データがなければヒストグラムは表示しません。
10. 利用者がすべてのヒストグラムを閉じた後、`LTspiceグラフを閉じるまで待機しています。`
    と表示し、LTspiceが開いていれば終了を待ちます。
11. LTspiceも終了した後、`--keep`がなければ、その実行で管理した自動生成物だけを
    削除して終了します。

`--run-only`では上記の生成手順を行わず、指定ASCから部品名、ばらつき番号、
有効解析タイプ、STEP条件および`.meas`名を読み、手順7以降だけを実行します。
設定TXTは探索も読込みもせず、入力ASCを削除しません。

## 【実行中の一時停止・再開・中断】

- シミュレーションの一時停止・再開および並列実行機能はありません。
- 実行中は5秒ごとに経過時間をコンソールへ表示します。
- 待ちきれない場合は、LTspiceシミュレーション実行中に`Ctrl+C`を押してください。
  CircuitDispersionが今回起動したLTspiceだけを終了し、終了コード130で終了します。
- 結果グラフまたはヒストグラムの表示中に`Ctrl+C`を押した場合も、
  `中断要求を受け付けました。`と`終了処理中です。`を直ちに表示します。
  その後、CircuitDispersionが表示用に起動したLTspiceだけを終了し、
  終了コード130で終了します。
- ヒストグラム表示中はTkタイマーで中断要求を短い間隔で確認します。
  Figureの反復再表示を行わないため、通常のヒストグラム表示状態を維持します。
  ヒストグラムを閉じる際は対応する監視タイマーも破棄前に解除します。
- 中断時は結果集計、グラフ表示および自動クリーンアップを行いません。生成ASC、NET、
  途中のRAW・LOGおよび解析マクロは、内容確認と診断のため残します。
- 利用者が別に起動したLTspiceは終了しません。対象PIDを安全に特定できない場合も、
  別のLTspiceを推測して終了しません。
- LTspiceシミュレーションの上限は600秒（10分）です。上限到達時は失敗として
  終了し、診断に使える生成物を残します。
- 結果表示中は、表示したLTspiceを閉じるまでCircuitDispersionは待機します。
- 中断後の続きから再開する機能はありません。必要なファイルを確認してから
  元ASCを指定して再実行します。

## 【生成されるファイル】

既定出力名を使用した場合の主なファイルは次のとおりです。`-o`指定時は、
固定名の解析マクロを除き、指定した生成ASCの基底名へ揃います。

| ファイル | 用途 | 扱い |
|---|---|---|
| `<元名>_CircuitDispersion_analysis.txt` | 部品設定と解析履歴 | 保存対象 |
| `<生成回路名>.asc` | ばらつき解析用回路図 | 生成物。生成だけ、`--keep`、異常終了では残す |
| `<生成回路名>.plt` | 通常RAW用プロット設定 | 元PLTからバイナリコピー |
| `<生成回路名>.log.plt` | 測定LOG用プロット設定 | 元LOG PLTからバイナリコピー |
| `Normal.meas`など | 解析関数マクロ | 生成ASCと同じフォルダーへ必要分を展開 |
| `<生成回路名>.net` | LTspice実行用NET | `--run`時の一時生成物 |
| `<生成回路名>.raw` | 通常波形 | `--run`時の一時生成物 |
| `<生成回路名>.log` | LTspiceログ | `--run`時の一時生成物 |
| `<生成回路名>.log.raw` | 測定LOGのプロット用RAW | 生成された場合に表示対象 |
| `<生成回路名>.result.log` | CircuitDispersionの集計結果 | 正式な保存結果。自動削除しない |

単独実行の結果ログは`<入力ASC基底名>.result.log`です。入力ASCと実行前から存在した
同名生成物は削除しません。ただし、同じ基底名のNET、RAWおよびLOGはLTspice実行で
更新される可能性があります。必要なら事前に別名ASCへコピーするか`--keep`を使用します。

生成ファイル名へ`_1`などの実行連番は付けません。

GUIでは既存生成先を一覧表示して置換確認します。非GUIの`--generate`は既定で
上書きします。`-n`指定時は、生成先が一つでも存在すれば処理前にエラー終了し、
一部だけを生成しません。内蔵正本と同じ解析マクロはそのまま再利用します。

## 【実行ログ】

CircuitDispersionは一般的な実行履歴ファイルを常時作成しません。進捗、警告および
エラーはコンソールへ表示します。LTspice実行コンソール用の空の`.exe.log`も
生成しません。

ファイル名設定後の確定は、ファイルダイアログへ標準の`IDOK`を直接送信します。

`--run`成功時は、元回路図にある有効な`.meas`を集計し、UTF-8（BOMなし）・LFの
`<生成回路名>.result.log`を保存します。同名ログは実行ごとに上書きします。
部品別解析では、リファレンス番号ごとの`最小値`、`最大値`、`範囲`を一行へ記録し、
単位は測定結果に従います。各行の先頭には解析内部番号ではなく、`R6`や
`Q1:BF`などの実部品名を記録します。

さらに`--run`時は、RAWではなくLTspiceの生`.log`から、現在の解析履歴で
ヒストグラムを有効にして選択した測定値だけを表示します。結果LOGには選択の有無に
かかわらず元ASCの全`.meas`を集計します。`Repate=0`の基準値は除き、
2個以上の異なる数値標本がある測定だけが対象です。単一値、数値化できない値、
または全値同一のときは表示しません。この動作は`--generate`や`--keep`とは無関係です。
ビン数は標本数によらずspicelib既定の50とし、空のビンも分布情報として残します。
横軸は原則として平均値の約±4標準偏差で、範囲外の実測値があれば自動的に拡張されます。
表示するプロットは、ウィンドウ外形の中心が画面の中心に合う位置へ開きます。
部品別ヒストグラムのタイトルは解析内部番号の`ref.1`ではなく、`R1`や
`Q1:BF`など設定に対応する実部品名を表示します。

結果LOGには、同じ統計標本の`統計データ数`、`平均値`および`標準偏差`も
記録します。`標準偏差`はヒストグラムの`stdev`と同じ母標準偏差です。
部品別に最小値、最大値および範囲を記録する結果は、測定セクションごとに
`範囲`の大きい順で並びます。最も大きなばらつき要因を先頭行で確認できます。
各部品に1個だけ残る集約測定値は再集計せず、`R1 PP = 値`のように
実部品名と元`.meas`の測定演算名を同じ行へ記録します。
解析全体に1個だけ残る集約測定値も再集計せず、`PP = 値`の1行だけを
記録します。同じ値の`基準値/最小値/最大値`とゼロの偏差は並べません。

```text
[測定:probe_ac]
R1 最小値= 5.9936836351 最大値=5.99592731081 範囲=    0.00224367571 dB
R2 最小値=5.99504519542 最大値=5.99504723807 範囲=2.04264999848e-06 dB
```

```text
[測定:vp1]
統計データ数=100
平均値=0.0273354351521
標準偏差=0.0127092295717
```

```text
[測定:vp1]
R1 PP = 0.0446459054947
R2 PP = 0.0792797803879
```

```text
[測定:vp1]
PP = 0.0854270458221
```

```text
LTspice実行中... 経過 00:00:10
LTspiceシミュレーション完了: 経過 00:02:34
測定結果を集計しています...
```

利用者向けのパス表示は、元回路図のフォルダーを基準とする相対パスを基本とします。

## 【使用時の注意事項】

- 元ASC、付属モデル、ライブラリ、元PLT、統合設定TXTおよび結果ログを
  自動生成物と判断して削除しないでください。
- LTspice関連ファイルはASCII、従来Unicode、UTF-8が混在します。一般的な
  UTF-8へ一律変換したりBOMを追加したりしないでください。
- 生成済み回路図ではなく、正常動作を確認した元ASCを入力してください。
- `.meas`がなければ、目的の特性を結果ログへ集計できません。
- `--run-only`は任意名の調整済みASCを正本とし、対応する設定TXTを使用しません。
  公差関数と値は変更できますが、有効解析タイプ、STEP、RefSelおよび番号の構造を
  変更した場合は単独実行の整合性検査に適合する必要があります。
- `--run-only -H`へ指定できるのはASCに有効な`.meas`名だけです。名前は
  大文字・小文字を区別しません。指定を省略するとヒストグラムを表示しません。
- ヒストグラムは解析設定で有効化して選択した`Repate`の繰返し測定を分布として
  表示します。単一測定値だけのOP解析などで表示されないのは正常動作です。
- ヒストグラム画面は最初から画面中央へ表示し、複数ある場合は識別できるよう
  2枚目以降を中央から32ピクセルずつ右下へずらして表示します。
- 選択可能なばらつき番号は0～15の最大16個です。
- `.plt`と`.log.plt`が両方あれば、既定では1つのLTspiceへ2グラフを表示します。
  `--mult`では別々のLTspiceへ表示します。
- LTspiceへグラフを自動表示した直後に、各グラフで`Zoom Extents`を実行します。
  LTspiceウィンドウへ`Ctrl+E`を送信して同機能を実行します。ショートカットを
  送信できない場合はコンソールへ警告を表示しますが、結果表示は継続します。
- 検出済みの波形ウィンドウは直後の`Ctrl+E`へ再利用します。シングル画面で
  2つ目のRAWを開く場合は、同じLTspiceの`Open`ボタンも再利用します。
- タイプ9のMAX/MIN総当たりは対象数に対して指数的に増加します。11個以上を
  指定すると確認画面が出ます。
- タイプ9では開始番号～終了番号の途中に、選択部品が存在しない欠番があっても
  実行できます。欠番は未使用ビットとなるため、その分だけ同じ条件の試行が重複します。
- 結果表示中にプロット設定やRAWを移動・削除しないでください。

## 【エラーと対処】

| 表示または症状 | 最初に確認すること |
|---|---|
| `ASC回路図ではありません` | 入力拡張子が`.asc`か確認 |
| 生成済み回路図を入力した旨のエラー | `_CircuitDispersion.asc`ではなく元ASCを指定 |
| 変換可能な部品がない | 対応部品、モデルまたは受け渡しパラメーターを確認 |
| 選択数の上限 | 対象を16個以内に減らす |
| 保存済み統合設定がない | 先にGUIで`設定だけ保存`または生成を実行 |
| 生成先が存在する | 上書きするか、`-o`で別名にする。保護目的の`-n`では正常な拒否 |
| `Autopy.ini`を作成できない | 起動時作業フォルダーの書込み権限とLTspice選択を確認 |
| `exec.Prog`が空、不正、または実行ファイルがない | ローカル`Autopy.ini`の`exec.Prog`を確認・再作成 |
| `exec.Lib`がない、または配下に`lib`がない | システムデータルートを`exec.Lib`へ指定し、その直下の`lib`を確認 |
| `exec.Libs`が空、不正、またはフォルダーがない | ローカル`Autopy.ini`の`exec.Libs`を確認・再作成 |
| RAWまたはLOGがない | 元ASC単体の解析、LTspiceログ、解析コマンドを確認 |
| 単独実行で解析タイプを取得できない | 有効な解析ブロックに`*3-1)`等が1個あるか確認 |
| `ヒストグラム対象の.meas測定名がありません` | ASCの有効な`.meas`名と`-H`指定を確認 |
| 表示可能なPLTとRAWがない | 元ASCに対応する`.plt`または`.log.plt`を準備 |
| 600秒で失敗 | 残されたNET、RAW、LOGとLTspiceの計算量を確認 |

`ModuleNotFoundError`、spicelib API差または生成結果の差が疑われる場合は、
次の順で確認します。

```text
python -c "import sys; print(sys.executable)"
python -m pip show spicelib
```

Python実行パス、spicelibの版`1.5.1`、表示されたインストール先を確認します。
指定版と異なる環境をその場で更新せず、開発用とは別の仮想環境で確認してください。

エラーや中断時は自動生成物を残す方針です。元ファイルを復元するのではなく、
残った生成物とコンソール表示から原因を確認してください。

## 【終了と後始末】

- 生成だけで終了した場合、生成ASC、関連PLTおよび解析マクロを残します。
- `--run --keep`では、ASC、NET、RAW、LOG、PLTおよび解析マクロを確認用に残します。
- `--run`が正常終了し、表示したLTspiceを閉じ、`--keep`がない場合は、
  その実行で管理したASC、NET、RAW、LOG、コピーPLTおよび新規展開マクロを削除します。
- 元ASC、元PLT、付属モデル、ライブラリ、統合設定TXT、既存利用者ファイルおよび
  `<生成回路名>.result.log`は削除しません。
- 部分失敗、タイムアウト、中断および異常終了時は診断用生成物を残します。
- 再実行前に、残っているLTspiceプロセス、生成ファイルの更新日時および
  結果ログが完了版かを確認します。必要なら`-o`で別名生成するか、内容を確認後に
  通常の上書き生成を行います。

## 【CircuitDispersion固有の項目】

### 解析対象、公差関数および番号

部品一覧では、抵抗、コンデンサー、インダクター、`.model`部品、サブサーキットおよび階層回路の
受け渡しパラメーターを選択します。選択対象には0～15の一意なばらつき番号を割り当て、
選択解除で空いた番号は次の対象へ再利用します。意図的に番号を詰める場合だけ
`番号を0から振り直す`を使用します。この操作は解析履歴内の番号指定も更新します。

| 関数 | 公差 |
|---|---|
| `A` | ±0.05% |
| `B` | ±0.1% |
| `C` | ±0.25% |
| `DD` | ±0.5% |
| `F` | ±1% |
| `G` | ±2% |
| `H` | ±3% |
| `J` | ±5% |
| `K` | ±10% |
| `M` | ±20% |
| `NM` | 通常値、最小値および最大値を個別指定 |

`D`は予約語のため使用せず、±0.5%には`DD`を使用します。カテゴリー一括設定では、
全抵抗、全コンデンサーまたは全インダクターを選択して同じ公差を適用するか、
現在選択済みの同カテゴリーだけへ公差を適用できます。一括設定の初期値は、抵抗が
`F ±1%`、コンデンサーとインダクターが`M ±20%`です。一括設定後も各行で個別変更できます。

`NM 個別範囲`は各部品行の公差関数コンボから選択します。選択した瞬間に
`NM範囲設定`ダイアログが開くため、通常値、最小値および最大値を入力します。
通常値には現在値が表示され、未設定の最小値と最大値は空欄です。3項目を入力して
`確定`すると、行の`設定済...`ボタンから再編集できます。キャンセル、Escapeまたは
閉じる操作では選択前の公差関数へ戻ります。カテゴリー一括設定には`NM`はありません。

`NM(100k,80k,130k,6)`は通常値`100k`、最小値`80k`、最大値`130k`、番号`6`です。
Monte Carloでは`80k～130k`の一様乱数、MaxMinでは`80k`または`130k`、Normalでは
`100k`になります。Gauss解析でも`NM`だけは`random()`による一様分布です。

### GUI操作と解析履歴

1. 部品一覧で対象と公差関数を選びます。
2. `設定だけ保存`、または`設定を保存して生成`を押します。
3. 生成する場合は解析タイプ、繰り返し数および対象番号等を設定します。
4. 統計解析でヒストグラムが必要なら`ヒストグラムを表示する`をチェックします。
   直ちに開く測定変数一覧から、表示したい`.meas`名を1個以上選びます。
5. `総合繰り返し回数（シミュレーション実行数）`を確認します。
6. `コマンドを更新`で挿入内容を確認します。
7. `解析設定を確定して回路図を生成`またはEnterキーで確定します。

設定TXTは先頭に`#`の説明を持ち、`[parts]`へ部品設定、
`[analysis_NNNN]`へ解析履歴を保存します。同じ解析タイプを再設定すると古い同タイプを
置き換え、回路図へ二重挿入しません。回路値が保存時から変わると警告します。
各解析履歴には`histogram_enabled=0|1`と、選択した測定名のカンマ区切り
`histogram_measures=...`も保存されます。これらを持たない旧設定TXTは読み込みません。

`解析履歴をリセット`は解析設定ダイアログ下部にあります。履歴だけを削除し、
部品選択、番号、公差および現在入力中の解析条件を残します。そのまま解析設定を
確定すると、現在の解析が`analysis_0001`になります。既存生成ASCはリセットした
時点では変更されません。

### 解析タイプ

| タイプ | 内容 |
|---|---|
| 0 | ばらつきを無効にして指定値で実行 |
| 1、2、3-1、3-2 | Monte Carlo解析 |
| 4、5、6-1、6-2 | Gauss解析 |
| 7 | 指定部品をMAXまたはMINへ固定 |
| 8 | 指定部品を順次単独でMAX、MINへ変更 |
| 9 | 連続する指定番号範囲のMAX/MIN組み合わせを総当たり |

タイプ2、5、7、8では選択済み部品から解析対象をさらに選びます。タイプ7では
対象ごとにMAXまたはMINを指定します。タイプ3、6、9では開始番号と終了番号を
使用します。解析設定画面には選択タイプで必要な項目だけを表示します。

タイプ1、2、3-1、3-2、4、5、6-1および6-2ではヒストグラム表示を選べます。
測定変数一覧には元ASCの有効な`.meas`名と`AVG`、`RMS`、`PARAM`等の演算名を
表示します。LOG読込みで内部的に生じる`_from`、`_to`、`refno`は表示しません。
最初の一覧をキャンセルするとヒストグラムのチェックも解除されます。選択後は
`測定変数を選択...`ボタンから変更できます。測定変数一覧でホイールを回しても、
背面の部品一覧はスクロールしません。

総合繰り返し回数はLTspiceの`.step`が開始値と終了値を含むものとして計算します。
`.step param Repate 0 100 1`は101回です。個別部品解析では、この回数へ
開始番号から終了番号までの部品数を掛けます。

### `.model`、サブサーキットおよび階層回路

`.model`部品では設計子に応じた候補パラメーターを表示し、回路図内または
直接参照するローカルモデルファイルから代表値を初期表示します。例えばモデルに
`BF=180`があれば、Q1/Q2は`BF / 180`から開始します。元モデル名へ`_CD`を付けた
AKO派生モデルを生成し、元モデルファイルは変更しません。

サブサーキットと階層回路では、トップ回路に直接記述された受け渡し値を一意な
`.param`へ置き換えます。外部ライブラリや階層回路内部を探索して、内部部品を
個別選択する機能ではありません。

### 生成ASC内の解析切替とGUI表示

生成ASCでは、現在解析、過去解析およびNormalを別々のテキストボックスへ記述します。
現在解析だけをSPICE Directiveとし、過去解析とNormalはコメントにします。LTspice上で
使用する一つをDirectiveへ、ほかをコメントへ切り替えることで、プログラムを
再実行せず解析条件を手動で切り替えられます。

部品選択画面は画面中央へ、解析設定画面は親画面中央へ、それぞれダイアログ自身の
中心を合わせて表示します。解析設定画面が前面にある間、その上のホイール操作で
背面の部品一覧はスクロールしません。対象部品一覧を使わない解析タイプでは、
解析設定ダイアログを小さい表示へ切り替えます。
部品選択画面のコンボボックス上でマウスホイールを回しても、公差関数などの設定値は
変わりません。ホイールは部品一覧のスクロールに使用し、設定値はドロップダウンを
開いて選択してください。
